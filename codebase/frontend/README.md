# Recall Learning frontend

Next.js app gồm:

- `/`: landing page kiêm pitch 6 phần, hỗ trợ phím mũi tên và Page Up/Page Down.
- `/chat`: giao diện chat tinh gọn, user switcher và bảng memory đã xác nhận.

Biến môi trường public:

```dotenv
NEXT_PUBLIC_API_URL=http://localhost:8000
```

Chạy phát triển:

```bash
npm install
npm run dev
```

Kiểm tra:

```bash
npm run lint
npm run build
```
